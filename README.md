# کارت‌ساز هوشمند نگاه جوان — 0.6.0 Premium

نسخه 0.6 روی سه ضعف اصلی نسخه‌های قبلی تمرکز دارد: عکس هوشمند، کاور هوشمند و طراحی جدا برای خبر کوتاه/متوسط/بلند.

## Smart Image Engine
- تشخیص چهره با ML Kit
- بررسی محدوده همه چهره‌ها، نه فقط مرکز یک چهره
- عکس گروهی یا عکس با نسبت نامناسب: Fit روی پس‌زمینه Blur
- عکس مناسب کراپ: Smart Crop روی سوژه
- جلوگیری از بریدن افراد در تصاویر گروهی
- حفظ کیفیت در عکس‌های کم‌رزولوشن

## Smart Cover
- در نبود عکس، کاور صرفاً یک گرادیان ساده نیست
- تم رنگی بر اساس دسته خبر
- واترمارک تایپوگرافیک بسیار ملایم از کلیدواژه/دسته
- طراحی اختصاصی خبر کوتاه
- ادامه خبر با طراحی کم‌حجم‌تر و خوانا

## Full Text
- متن کامل حفظ می‌شود
- ابتدا تلاش برای یک کارت با اندازه فونت پریمیوم
- اگر جا نشد، تقسیم در مرز پاراگراف/جمله/کلمه
- هیچ خلاصه اجباری جای متن اصلی را نمی‌گیرد
- عکس فقط کارت اول را اشغال می‌کند تا صفحات ادامه فضای بیشتری داشته باشند
