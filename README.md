### هوشمندی
اپ در صورت نبود Backend نیز با Smart Local کار می‌کند. اگر Backend AI تنظیم شود، تحلیل آنلاین استفاده می‌شود و در خطا یا قطع اینترنت، اپ خودکار به Smart Local برمی‌گردد.

Backend:
- OPENAI_API_KEY
- OPENAI_MODEL (اختیاری)

Android build property:
```properties
AI_BASE_URL=https://YOUR-BACKEND-DOMAIN/
```

کلید API نباید داخل APK قرار بگیرد.
