# کارت‌ساز هوشمند پایگاه خبری نگاه جوان

اپ Android آنلاین برای تبدیل متن خبر + عکس اختیاری به کارت خبری آماده شبکه‌های اجتماعی.

## نسخه فعلی: 0.2.0 — Premium Templates

### مسیر اصلی
متن خبر → تحلیل هوشمند → انتخاب یکی از 3 قالب → انتخاب ابعاد → پیش‌نمایش → PNG/اشتراک

### قالب‌های پریمیوم
- **امضای نگاه**: هویت اصلی قرمز/مشکی/سفید، مناسب اکثر خبرها
- **فوری پلاس**: تیتر درشت، نوار Breaking و کنتراست بالا برای خبرهای فوری
- **ادیتوریال**: پنل روشن مجله‌ای برای گزارش، تحلیل و خبرهای رسمی

اگر خبر «فوری» تشخیص داده شود، اپ به‌طور خودکار «فوری پلاس» را پیشنهاد می‌کند.

## اجرای Android
1. در ویندوز ابتدا `setup-gradle.bat` را یک‌بار اجرا کنید.
2. پوشه را با Android Studio باز کنید.
3. JDK 17 را برای Gradle انتخاب کنید.
4. Sync Project with Gradle Files.
5. روی Android 12 تا Android 16 اجرا کنید.

> اگر Backend تنظیم نشده باشد، اپ همچنان با موتور داخلی کار می‌کند.

## فعال‌کردن AI آنلاین
Backend داخل پوشه `server/` است. آن را روی Railway یا هر سرور HTTPS اجرا کنید.

Environment variableهای Backend:
- `OPENAI_API_KEY` = کلید API
- `OPENAI_MODEL` = اختیاری؛ پیش‌فرض `gpt-5.6-luna`

در `gradle.properties`:
```properties
AI_BASE_URL=https://YOUR-BACKEND-DOMAIN/
```

**کلید OpenAI را هرگز داخل APK قرار ندهید.**
