# کارت‌ساز هوشمند نگاه جوان — 0.9.0 Visual Identity Edition

نسخه 0.9 طراحی کارت را از «سه قالب شبیه هم» به سه هویت بصری مستقل تبدیل می‌کند.

## هویت ۱ — امضای طلایی
- پس‌زمینه سرمه‌ای/مشکی
- قاب باریک طلایی دو لایه
- عنوان فارسی با رنگ طلایی
- negahjavaan و negahjavan.ir به‌صورت واضح
- امضای دامنه در پایین کارت
- الهام از طراحی رسانه‌ای لوکس و مینیمال

## هویت ۲ — استودیو بنفش
- فضای نیوزروم دیجیتال
- شبکه هندسی بنفش
- هدر مستقل با NEGAH JAVAAN • NEWSROOM
- امضای بنفش و دامنه در پایین
- بدون حباب، دایره یا لکه تزئینی

## هویت ۳ — ردلاین ادیتوریال
- مشکی/سفید/قرمز
- خط عمودی قرمز و ترکیب نامتقارن
- هدر جسور
- footer دوطرفه برای social و website
- مناسب کارت‌های مینیمال و جدی

## ثابت در هر سه هویت
- negahjavaan
- negahjavan.ir
- پایگاه خبری نگاه جوان
- واترمارک وسط وجود ندارد

- طراحی به موضوع خبر وابسته نیست
