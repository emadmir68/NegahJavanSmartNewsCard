# کارت‌ساز نگاه جوان — استودیو ۱.۵.۹

ساخت کارت خبر، پست، استوری و پوشش ویدئو در اندروید با پیش‌نمایش و خروجی از یک رندرر مشترک.

## امکانات این شاخه

- تیتر با اندازهٔ دستی یا خودکار، شش فونت واقعی و چهار نسبت خروجی.
- قالب مجله‌ای، عکس‌محور، خبر فوری، امضای سبز/طلایی، نقل‌قول و عدد خبر.
- نمایش کامل عکس یا برش با کنترل زوم و جابه‌جایی.
- حفظ متن بلند با صفحه‌بندی؛ ادامهٔ خبر در فضای کامل صفحه.
- متن پایانی کاروسل اختیاری و قابل‌ویرایش.
- ذخیرهٔ پروژه و کپشن کامل، خروجی PNG و MP4 و بازکردن پنجرهٔ اشتراک‌گذاری.
- پیشنهاد تیتر و خلاصه از متن ورودی به‌صورت محلی؛ پیشنهادها نیاز به بازبینی دارند.

انتشار نهایی در برنامهٔ مقصد انجام می‌شود. آزمون ویدئو و ارسال واقعی روی گوشی هنوز بخشی از تأیید این نسخه نیست.

## دریافت نسخه

پس از موفقیت ساخت، بستهٔ نصب در `dist/NegahJavan-Studio-1.5.9.zip` و تصاویر رندرشده در `docs/design/previews/<source SHA>/` ذخیره می‌شوند. بسته شامل APK، یادداشت نسخه و SHA دقیق سورس است. فایل ZIP از GitHub قابل دانلود است؛ به فایل موقت محیط گفتگو متکی نیست.

[تغییرات نسخه و نصب](RELEASE-1.5.9.md) · [گزارش بازطراحی](docs/design/ITERATION-02.md)

## ساخت و بررسی

JDK 17، Android SDK 36، Build Tools 35 و Gradle 8.13:

```sh
bash ./gradlew testDebugUnitTest lintDebug assembleDebug
```

تست‌های Robolectric از رندر بومی Android استفاده می‌کنند؛ خروجی‌های تصویری در `app/build/reports/studio-158/` نوشته می‌شوند. تصاویر و خبرهای تست نمونهٔ مصنوعی‌اند و گزارش واقعی محسوب نمی‌شوند.

این شاخه از `main` مستقل است. کد ابزارها و backend قدیمی در مخزن حفظ شده است؛ قابلیت‌های بالا مربوط به StudioApp فعال در همین شاخه است.
