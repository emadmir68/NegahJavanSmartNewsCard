# کارت‌ساز هوشمند نگاه جوان — 0.7.0

این نسخه بر اساس تست واقعی استوری بازطراحی شد.

## تغییرات اصلی
- واترمارک متنی وسط کارت کاملاً حذف شد.
- حالت پیش‌فرض خبر بدون عکس، کارت متنی تمیز و بدون تصویر اضافی است.
- هویت رسانه‌ای بالای کارت پررنگ‌تر شد:
  - negahjavaan
  - negahjavan.ir
  - پایگاه خبری نگاه جوان
- یک دکمه «ساخت تصویر خودکار برای این خبر» اضافه شد.
- تصویر خودکار روی دستگاه ساخته می‌شود و نیاز به اینترنت یا API ندارد.
- تصویر خودکار هیچ متن، لوگو یا واترمارکی داخل خودش ندارد تا تیتر و برند کارت واضح بماند.
- موتور تصویر با توجه به محتوای خبر بین صحنه‌های جاده، آب‌وهوا، قضایی، شهری، اقتصادی، ورزشی، فناوری و عمومی انتخاب می‌کند.
- عکس دستی و تصویر خودکار هر دو همچنان از Crop/Fit هوشمند عبور می‌کنند.
- متن کامل و صفحه‌بندی خودکار نسخه 0.6 حفظ شده است.
