# کارت‌ساز هوشمند پایگاه خبری نگاه جوان

MVP اندروید آنلاین برای تبدیل متن خبر + عکس اختیاری به کارت خبری آماده شبکه‌های اجتماعی.

## امکانات این نسخه
- ورود متن کامل خبر
- انتخاب عکس اختیاری از گوشی
- تحلیل آنلاین خبر از طریق Backend AI
- fallback داخلی در صورت نبود اینترنت/Backend
- تشخیص تیتر، لید و دسته خبر
- چهار خروجی: Story 9:16، Landscape 16:9، Portrait 4:5 و Square 1:1
- طراحی برند نگاه جوان با تم قرمز/مشکی/سفید
- تاریخ شمسی خودکار
- ذخیره PNG در Pictures/NegahJavan
- Share مستقیم از Android

## اجرای Android
1. در ویندوز ابتدا `setup-gradle.bat` را یک‌بار اجرا کنید (فقط برای آماده‌کردن Gradle Wrapper).
2. پوشه را با Android Studio باز کنید.
3. JDK 17 را برای Gradle انتخاب کنید.
4. Sync Project with Gradle Files.
5. روی Android 12 تا Android 16 اجرا کنید.

> اگر Backend تنظیم نشده باشد، اپ همچنان با موتور داخلی کار می‌کند.

## فعال‌کردن AI آنلاین
Backend داخل پوشه `server/` است. آن را روی Railway یا هر سرور HTTPS اجرا کنید.

Environment variableهای Backend:
- `OPENAI_API_KEY` = کلید API
- `OPENAI_MODEL` = اختیاری؛ پیش‌فرض `gpt-5.6-luna`

بعد در فایل `gradle.properties` پروژه Android اضافه کنید:

```properties
AI_BASE_URL=https://YOUR-BACKEND-DOMAIN/
```

سپس اپ را دوباره Build کنید.

**کلید OpenAI را هرگز داخل APK قرار ندهید.** فقط Backend باید کلید را نگه دارد.

## وضعیت MVP
این نسخه پایه عملیاتی است. فاز بعدی: 3 طرح پیشنهادی برای هر خبر، ساخت تصویر AI برای خبر بدون عکس، کنترل لوگو/رنگ از پنل آنلاین، قالب‌های «فوری/ویژه/گزارش تصویری»، و ویرایش دستی محدود قبل از خروجی.
