# کارت‌ساز هوشمند پایگاه خبری نگاه جوان

## نسخه 0.3.0 — Auto Mode

در این نسخه کاربر فقط متن خبر را وارد می‌کند و در صورت داشتن عکس، آن را اضافه می‌کند. تصمیم‌های اصلی به‌صورت خودکار گرفته می‌شوند.

### منطق هوشمند
- تشخیص خودکار خبر کوتاه، متوسط یا بلند
- خبر کوتاه → یک کارت فشرده
- خبر متوسط → یک کارت کامل
- خبر بلند → چهار اسلاید خودکار
- تشخیص دسته خبر و انتخاب برچسب مناسب
- «فوری» فقط برای خبر واقعاً فوری
- انتخاب خودکار قالب مناسب
- ساخت استوری 9:16
- ساخت پست/کاروسل 4:5
- خبر بدون عکس → کاور موضوعی هوشمند
- خبر عکس‌دار → کراپ چهره‌محور با ML Kit
- ذخیره و اشتراک یک‌جا

### سه قالب
- امضای نگاه
- فوری پلاس
- ادیتوریال

### Backend AI
اگر Backend تنظیم شود، تحلیل تحریریه‌ای از سرویس AI انجام می‌شود. اگر Backend در دسترس نباشد، موتور Smart Local داخل اپ تصمیم‌گیری را ادامه می‌دهد.

متغیرهای Backend:
- `OPENAI_API_KEY`
- `OPENAI_MODEL` (اختیاری)

در Android:
```properties
AI_BASE_URL=https://YOUR-BACKEND-DOMAIN/
```

کلید API نباید داخل APK قرار بگیرد.
