# کارت‌ساز هوشمند نگاه جوان — 0.5.0

نسخه 0.5 هسته خروجی را از «خلاصه‌سازی» به **Smart Pagination** تغییر می‌دهد.

## قانون اصلی
متن کامل کاربر حفظ می‌شود. اپ ابتدا تلاش می‌کند کل خبر را با فونت خوانا روی یک کارت قرار دهد. اگر متن جا نشود، ادامه آن بدون حذف و بدون خلاصه‌سازی به کارت بعدی منتقل می‌شود و این روند تا پایان متن ادامه دارد.

## عکس
اگر عکس وجود داشته باشد:
- فقط کارت اول عکس دارد.
- عکس داخل باکس جمع‌وجور و پریمیوم در بالای کارت قرار می‌گیرد.
- کراپ چهره‌محور ML Kit استفاده می‌شود.
- متن زیر عکس از بالا به پایین ادامه پیدا می‌کند.
- کارت‌های بعدی برای ادامه متن فضای بیشتری دارند.

## برندینگ
سه شناسه به صورت تایپوگرافی و غیرخطی در هدر قرار می‌گیرند:
- negahjavaan
- negahjavan.ir
- پایگاه خبری نگاه جوان

## خروجی
- Story 1080×1920
- Post/Carousel 1080×1350
- تعداد کارت برای هر فرمت مستقل و بر اساس فضای واقعی محاسبه می‌شود.
- PNG باکیفیت
- اشتراک مستقیم تک‌تصویر یا چندتصویر

## هوشمندی
- تشخیص دسته و برچسب
- «فوری» فقط برای فوریت واقعی
- حفظ متن کامل
- تشخیص واقعی ظرفیت با StaticLayout
- شکستن متن روی مرز جمله/پاراگراف/کلمه
- حداقل اندازه فونت برای جلوگیری از ریزشدن غیرقابل‌خواندن
- Smart Local بدون سرور
- AI آنلاین فقط برای متادیتا و دسته‌بندی؛ متن اصلی روی دستگاه دست‌نخورده صفحه‌بندی می‌شود.
