# کارت‌ساز هوشمند نگاه جوان — 1.4.0

## پست ویدیویی
از «افزودن فیلم و ارسال پست» یک ویدیو انتخاب کنید؛ تیتر و خلاصه قابل ویرایش است.
دو قالب طلایی/وزیرمتن و روشن/لاله‌زار، دو اندازهٔ پست ۴:۵ و ریلز ۹:۱۶ و پیش‌نمایش متحرک دارد.
«ارسال پست» فیلم را با صدا به MP4 تبدیل می‌کند، در گالری ذخیره می‌کند و صفحهٔ اشتراک را باز می‌کند.
کپشن کامل کپی می‌شود؛ انتشار نهایی در اینستاگرام توسط کاربر انجام می‌شود.
فیلم برای پرکردن قاب از مرکز برش می‌خورد. هنگام خروجی برنامه را باز نگه دارید؛ لغو ساخت نیز در دسترس است.
پردازش روی گوشی انجام می‌شود و فایل ویدیو روی سرور آپلود نمی‌شود.

تست دستگاه: `./gradlew connectedDebugAndroidTest` با ویدیوهای مصنوعی صدادار و بی‌صدا؛ بررسی مدت، صدا، ابعاد و ذخیره در گالری.

## Smart
- Smart Composition برای تیتر، متن، فاصله‌ها، فضای عکس و Safe Area
- Smart Pagination با حفظ متن کامل
- Smart Image با ML Kit و Smart Crop / Fit Blur
- Exact Preview از همان Bitmap Renderer خروجی
- Hybrid Analysis با Backend آنلاین و fallback محلی
- Online AI Image با fallback گرافیکی محلی
- ذخیره پیش‌نویس متن و URI عکس انتخابی

## خروجی‌ها
- Story 1080×1920
- Portrait 1080×1350
- Square 1080×1080
- Landscape 1920×1080
- PNG و Share مستقیم

## Backend
پوشه server شامل FastAPI است. مدل پیش‌فرض تحلیل gpt-6-luna و مدل تصویر gpt-image-2.5-flare است.

برای فعال شدن AI آنلاین:
- OPENAI_API_KEY روی Backend
- AI_BASE_URL هنگام Build اپ

در نبود Backend یا API، برنامه بدون Crash با موتور محلی ادامه می‌دهد.
