# Studio 1.7.0 — actual brand logo and typography

The user rejected the previous design because title and article typography still looked ordinary and supplied the actual نگاه جوان logo. This iteration replaces the invented eye emblem with the supplied pixel asset and replaces the green/gold frame system with black, white and the logo's red.

The default headline uses the actual Estedad Black 900 font file, not a synthetic bold. Article/summary uses a separately selectable body face, initially Cairo Regular 400. Body line spacing is measured and paginated independently of headline spacing. Text never uses letter-spacing that would break Persian joining.

The brand header accommodates the logo's compact wordmark or full circular form at the selected size. Source pixels and colors are retained, with an explicit white logo support area. Title and body fonts, logo display mode and typography version persist with each project. Automatic legacy Vazirmatn defaults migrate; manual size selections and other selected headline faces remain available.

Native review outputs compare against 1.6.0 using the same synthetic photo and copy. Bounds checks include logo clearance, manual headlines, independent body fonts, long content, all styles and all output ratios. Aesthetic acceptance remains the user's decision; real-device video/Instagram behavior is not tested in this environment.
