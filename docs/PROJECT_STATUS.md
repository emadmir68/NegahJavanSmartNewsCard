# وضعیت پروژه — نسخه 0.2.0

## قفل‌های فعلی
- نام رسانه: پایگاه خبری نگاه جوان
- Android 12–16+
- Kotlin + Jetpack Compose
- آنلاین + fallback داخلی
- هویت پایه: قرمز / مشکی / سفید
- خروجی: 9:16، 16:9، 4:5، 1:1
- مسیر: متن/عکس → تحلیل → قالب → ابعاد → Preview → PNG/Share

## انجام‌شده در 0.2.0
1. بازطراحی رابط اصلی اپ
2. سه قالب مستقل Premium: امضای نگاه، فوری پلاس، ادیتوریال
3. پیشنهاد خودکار فوری پلاس برای دسته Breaking
4. هماهنگی قالب انتخابی با Renderer خروجی PNG
5. بهبود نمایش وضعیت Online/Local
6. ارتقای versionName به 0.2.0
