# وضعیت پروژه — نسخه 0.1.0

## تصمیم‌های قفل‌شده
- نام رسانه: پایگاه خبری نگاه جوان
- پلتفرم: Android 12–16+
- UI: Kotlin + Jetpack Compose
- آنلاین + fallback آفلاین
- هویت اصلی: قرمز / مشکی / سفید
- مسیر اصلی کاربر: متن/عکس → تحلیل هوشمند → پیش‌نمایش → انتخاب ابعاد → ذخیره/اشتراک

## فاز بعدی پیشنهادی
1. موتور چندقالبی Premium (حداقل 8 Layout مستقل)
2. Crop هوشمند چهره/سوژه
3. AI image generation برای خبر بدون عکس
4. پنل آنلاین Template/Brand
5. کپشن و هشتگ قابل کپی
6. تاریخ/لوگو/آدرس قابل تنظیم از پنل
7. خروجی کاروسل چندصفحه‌ای برای متن بلند
