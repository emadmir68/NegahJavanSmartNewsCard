# وضعیت نسخه 0.3.0

## Auto Mode
- انتخاب دستی قالب از مسیر اصلی حذف شد.
- انتخاب دستی ابعاد از مسیر اصلی حذف شد.
- کاربر متن را می‌دهد و اپ درباره طول خبر، دسته، برچسب، قالب و تعداد اسلاید تصمیم می‌گیرد.

## متن بلند
- به‌صورت خودکار به 4 اسلاید تقسیم می‌شود.
- اسلاید 1: تیتر و خلاصه
- اسلاید 2: نکات اصلی
- اسلاید 3: ادامه خبر
- اسلاید 4: جمع‌بندی

## عکس
- با عکس: تشخیص چهره و نقطه تمرکز برای Crop
- بدون عکس: Smart Cover موضوعی بر اساس دسته خبر

## برچسب
- فوری فقط برای خبرهای واقعاً فوری
- پشتیبانی از قضایی، مطالبه مردم، گزارش، اطلاعیه، ویژه، محلی و دسته‌های خبری

## خروجی
- مجموعه استوری
- پست یا کاروسل
- ذخیره همه خروجی‌ها
