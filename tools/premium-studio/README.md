# نگاه جوان — Premium Studio 3.1

فایل مستقل `NegahJavan_Premium_Studio_3.html` را دانلود و در مرورگر باز کنید. نصب یا اتصال به اینترنت برای استفاده از ابزار لازم نیست. این پوشه نسخهٔ HTML را نگه می‌دارد و اپ اندروید را تغییر نمی‌دهد.

## اصلاحات
- خروجی PNG از SVG خودکفا با data URL، همراه با جهت RTL و فونت وزیرمتن جاسازی‌شده.
- سه اندازهٔ دقیق: 1080×1920، 1080×1350 و 1080×1080.
- محاسبهٔ فضای مشترک تیتر و لید، اندازهٔ پیش‌فرض متناسب‌تر و تنظیم دستی.
- هشدار و مسدودکردن خروجی برای متن بیش‌ازحد بلند؛ متن اصلی در کادر ویرایش محفوظ می‌ماند.
- فشرده‌سازی عکس تا ضلع بزرگ 2048 پیکسل، اعتبارسنجی فایل و حذف مستقل عکس و لوگو.
- تغییر رنگ انتخاب بدون ایجاد رنگ‌های تو‌در‌تو؛ دکمهٔ حذف رنگ.
- ذخیره و بازیابی متن، رنگ‌ها، تصویر، لوگو و تنظیمات روی همان مرورگر. اگر ذخیره‌سازی مرورگر محدود باشد، پیام روشن نمایش داده می‌شود.
- دریافت دوباره، نمایش تصویر و اشتراک‌گذاری در مرورگرهای پشتیبان.

وزیرمتن تحت SIL Open Font License 1.1 توزیع شده است. متن کامل مجوز داخل HTML آمده است.

## آزمون
```sh
npm install
npx playwright install chromium
npm test
```

برای مرورگر محلی موجود می‌توان متغیر `STUDIO_CHROMIUM` را به مسیر آن تنظیم کرد. `STUDIO_HTML` مسیر اختیاری HTML تحت آزمون است.

آزمون، تصاویر نمونه را محلی می‌سازد. پوشش شامل 18 ترکیب قالب/اندازه/وجود عکس، 22 خروجی PNG، ابعاد واقعی، فونت، RTL، متن بلند، متن چندخطی فارسی/انگلیسی، تغییر رنگ، حذف عکس و لوگو، تنظیم دستی، پیش‌نویس تصویردار، فایل خراب و حجیم و خطای ذخیره‌سازی است. درخواست‌های شبکه مسدود می‌شوند.

اعتبارسنجی در 2026-10-25: Chromium 134، عرض صفحهٔ 393 پیکسل، 22 خروجی موفق، صفر درخواست شبکه و صفر خطای JavaScript. یک نمونهٔ PNG نیز با تصویر DOM در ابعاد کامل مقایسه شد و تفاوت میانگین کمتر از 0.1 از 255 بود.

آزمون روی گوشی واقعی Android یا iOS انجام نشده است. متن بیش‌ازحد بلند خودکار صفحه‌بندی نمی‌شود؛ باید کوتاه‌تر شود یا اندازه/قالب آن تغییر کند.
