# نگاه جوان — استودیو ۴

فایل مستقل `NegahJavan_Premium_Studio_3.html` را دانلود و در مرورگر باز کنید. فونت و ابزارها داخل همین فایل هستند؛ استفاده از آن به اینترنت نیاز ندارد. نام فایل برای حفظ پیوند نسخه‌های قبلی ثابت مانده است. این پوشه نسخهٔ HTML را نگه می‌دارد و اپ اندروید را تغییر نمی‌دهد.

## طراحی تازه
- پیش‌نمایش در ابتدای صفحهٔ موبایل؛ در دسکتاپ کنار ویرایشگر.
- صفحهٔ اصلی فقط عکس، تیتر و خلاصه دارد. متن کامل خبر، تنظیمات ظاهر و کپشن در بخش‌های بازشونده‌اند.
- دو رنگ تیره و روشن، دو چیدمان «عکس و تیتر» و «فقط تیتر»؛ نشان رسانه کوچک‌تر و تزئینات تکراری حذف شده‌اند.
- عکس و نوشته از هم جدا هستند. عکس به‌صورت کامل نمایش داده می‌شود؛ برش و بزرگ‌نمایی اختیاری‌اند.
- اندازهٔ تیتر و تعادل سطرها خودکار است؛ اندازهٔ دستی، رنگ بخشی از تیتر، لوگوی شخصی و تنظیم جای عکس در تنظیمات ظاهر باقی‌اند.
- پیش‌نویس قبلی با متن، رنگ تیتر، عکس و لوگو بازیابی می‌شود؛ چیدمان قدیمی به طرح جدید منتقل می‌شود.

## استفاده
1. عکس و تیتر را وارد کنید. خلاصه اختیاری است.
2. برای ساخت از متن کامل، بخش «ساخت از متن کامل خبر» را باز کنید و متن را بچسبانید. تیتر اولیه و خلاصه از همان ورودی انتخاب می‌شوند؛ واقعیت تازه‌ای تولید نمی‌شود. متن کامل در پیش‌نویس و کپشن می‌ماند. ویرایش دستی تیتر و خلاصه حفظ می‌شود.
3. «ارسال پست» تصویر 1080×1350 و «ارسال استوری» تصویر 1080×1920 می‌سازد. مربع 1080×1080 از نوار پیش‌نمایش انتخاب می‌شود. دکمهٔ دانلود، PNG همان اندازهٔ جاری را دریافت می‌کند.
4. در مرورگر دارای Web Share، پنجرهٔ اشتراک‌گذاری باز می‌شود. مقصد و انتشار نهایی را کاربر انتخاب می‌کند؛ HTML مستقیماً در حساب اینستاگرام منتشر نمی‌کند.
5. اگر ارسال فایل پشتیبانی نشود، PNG دانلود می‌شود و پیوند دریافت دوباره و نمایش تصویر باقی می‌ماند. برخی مرورگرها برای بازکردن پنجرهٔ اشتراک‌گذاری به لمس دوبارهٔ ارسال نیاز دارند.

متن کامل برای کپشن حفظ می‌شود، اما متن بسیار بلند خودکار صفحه‌بندی نمی‌شود. اگر متن کارت پس از تنظیم اندازه جا نشود، دریافت تصویر ناقص مسدود می‌شود. خلاصهٔ استخراجی را پیش از انتشار مرور کنید.

## آزمون
```sh
npm install
npx playwright install chromium --only-shell
npm test
```

`STUDIO_CHROMIUM` مسیر اختیاری مرورگر موجود و `STUDIO_HTML` مسیر اختیاری فایل تحت آزمون است. عکس‌ها و لوگوی آزمون به‌صورت محلی تولید می‌شوند؛ تصویر آپلودشدهٔ کاربر در مخزن قرار نگرفته است.

اعتبارسنجی 2026-10-26 با Chromium 134:
- عرض‌های 320، 393، 768 و 1440 پیکسل، بدون سرریز افقی صفحه.
- 24 ترکیب اندازه، چیدمان، رنگ و وجود عکس؛ مجموعاً 27 خروجی در آزمون عمومی و دو خروجی مستقل از دکمه‌های ارسال.
- جدایی عکس و تیتر، نمایش کامل عکس عمودی، سطر پایانی متعادل و ابعاد صحیح PNG.
- جلوگیری از خروجی متن سرریز، حفظ متن منبع، ویرایش دستی، رنگ‌بندی، لوگو، خطای تصویر و خطای ذخیره‌سازی.
- بازیابی پیش‌نویس نسخهٔ ۴ و انتقال محتوای پیش‌نویس 3.2.
- موفقیت، لغو و خطای فعال‌سازی Web Share فقط با جایگزین آزمایشی API؛ هیچ ارسال واقعی انجام نشده است.
- صفر درخواست شبکه و صفر خطای JavaScript در آزمون‌ها؛ اختلاف میانگین یک خروجی PNG با پیش‌نمایش کامل DOM حدود 0.070 از 255.

آزمون روی گوشی واقعی و دریافت فایل در اپ اینستاگرام هنوز انجام نشده است.
