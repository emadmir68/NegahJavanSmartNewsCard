# نگاه جوان — Premium Studio 3.2

فایل مستقل `NegahJavan_Premium_Studio_3.html` را دانلود و در مرورگر باز کنید. فونت و ابزارها داخل همین فایل هستند و برای استفاده به اینترنت نیاز ندارند. این پوشه نسخهٔ HTML را نگه می‌دارد و اپ اندروید را تغییر نمی‌دهد.

## روند استفاده
1. عکس خبر و تیتر/خلاصه را وارد کنید. می‌توانید متن کامل خبر را بچسبانید تا تیتر اولیه و خلاصه از همان متن استخراج شوند.
2. حالت «خودکار» عکس و متن را جدا می‌چیند. نمایش کامل عکس، حالت پیش‌فرض است؛ گزینهٔ پرکردن قاب نیز وجود دارد.
3. «ارسال پست» خروجی 1080×1350 و «ارسال استوری» خروجی 1080×1920 را آماده می‌کند. گزینهٔ مربع 1080×1080 نیز باقی مانده است.
4. در مرورگر دارای Web Share، پنجرهٔ اشتراک‌گذاری باز می‌شود. مقصد و انتشار نهایی را کاربر انتخاب می‌کند. این HTML مستقیماً پست یا استوری را در حساب اینستاگرام منتشر نمی‌کند و مقصد خاصی را تضمین نمی‌کند.
5. در مرورگر فاقد ارسال فایل، PNG دانلود می‌شود. لینک دریافت دوباره و نمایش تصویر باقی می‌ماند.

## تغییرات 3.2
- حالت پیش‌فرض پست، با عکس بدون پوشاندن سوژه توسط متن یا سایهٔ تیره.
- جداسازی فضای عکس و متن، فونت متناسب‌تر، تعادل سطرهای تیتر و لید و کاهش سطر تک‌کلمه‌ای.
- متن کامل خبر اختیاری؛ تیتر اولیه و خلاصهٔ کوتاه از متن ورودی انتخاب می‌شوند. خلاصه‌سازی استخراجی است و خبر یا واقعیت تازه‌ای تولید نمی‌کند. متن کامل در پیش‌نویس و کپشن محفوظ می‌ماند.
- ویرایش دستی تیتر و لید محترم می‌ماند؛ گزینهٔ آماده‌سازی خودکار می‌تواند خلاصه را دوباره از منبع بسازد.
- کپشن قابل کپی، ذخیرهٔ پیش‌نویس و بازیابی عکس/لوگو/تنظیمات.
- ارسال مجدد از فایل آماده، رسیدگی به لغو ارسال و حفظ مسیر دانلود در صورت محدودیت مرورگر.
- جلسهٔ تازه با متن خبر خالی شروع می‌شود تا خبر نمونهٔ قبلی ناخواسته منتشر نشود.
- رفع‌های 3.1 باقی‌اند: PNG خودکفا، RTL، وزیرمتن جاسازی‌شده، کنترل سرریز، رنگ‌بندی بدون تو‌در‌تویی و فشرده‌سازی عکس.

خلاصهٔ خودکار بر اساس جمله‌ها و طول مناسب هر اندازه انتخاب می‌شود؛ خروجی را پیش از انتشار مرور کنید. متن بیش‌ازحد بلند خودکار صفحه‌بندی نمی‌شود و اگر پس از تنظیم در کارت جا نشود، خروجی ناقص مسدود می‌شود.

## آزمون
```sh
npm install
npx playwright install chromium
npm test
```

`STUDIO_CHROMIUM` مسیر اختیاری مرورگر موجود و `STUDIO_HTML` مسیر اختیاری فایل تحت آزمون است. تصاویر آزمون به‌صورت محلی ساخته می‌شوند و تصویر آپلودشدهٔ کاربر در مخزن قرار نگرفته است.

اعتبارسنجی 2026-10-26:
- Chromium 134 با عرض صفحهٔ 393 پیکسل.
- 24 ترکیب قالب/اندازه/وجود عکس و 28 خروجی PNG در آزمون عمومی.
- دو خروجی مستقل از دکمه‌های ارسال پست و استوری با ابعاد واقعی صحیح.
- عکس عمودی بدون برش اجباری یا هم‌پوشانی متن؛ تیتر نمونه در پایان بیش از یک کلمه دارد.
- تیتر و خلاصهٔ استخراجی، حفظ متن کامل، احترام به ویرایش دستی و بازیابی پیش‌نویس.
- API اشتراک‌گذاری با جایگزین آزمایشی برای موفقیت، لغو و نبودِ مجوز فعال‌سازی آزمایش شده؛ هیچ ارسال واقعی به شخص یا سرویس خارجی انجام نشده است.
- تفاوت میانگین یک نمونهٔ PNG و پیش‌نمایش DOM حدود 0.0013 از 255؛ صفر درخواست شبکه و صفر خطای JavaScript در آزمون‌ها.

آزمون روی گوشی واقعی و دریافت فایل در اپ اینستاگرام هنوز انجام نشده است. برخی مرورگرها برای ارسال فایل آماده به لمس دوبارهٔ دکمه نیاز دارند. قرارداد API: https://www.w3.org/TR/web-share/
